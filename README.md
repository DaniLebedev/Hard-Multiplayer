# Hard Multiplayer

Асимметричный мультиплеер для **Hard Bullet**: игрок в VR проходит игру как обычно, а второй человек
без копии игры открывает браузер и играет за **призрака** — спавнит врагов за спиной, бросает взрывные
бочки, шумит, шепчет и на время становится видимым.

Проект состоит из трёх частей:

| Часть | Где работает | Что делает |
| --- | --- | --- |
| **Мод** (`mod/`) | В игре, через BepInEx 6 IL2CPP | Читает состояние игры, исполняет команды призрака, отправляет снапшоты |
| **Relay** (`relay/`) | Node.js на любом хосте | Комнаты, WebSocket-мост, мягкая проверка команд, раздача браузерного клиента |
| **Клиент призрака** (`ghost-app/`) | Браузер друга | Тактическая карта, способности, энергия, кулдауны, звук |

Другой человек **не должен владеть Hard Bullet и не должен устанавливать мод**. Ему нужен только браузер
и код комнаты.

```
┌──────────────────────────┐        WebSocket         ┌─────────────────┐
│ Hard Bullet + BepInEx мод│ ───────────────────────► │  Relay (Node)   │
│ (VR-игрок)               │ ◄─────────────────────── │  комнаты + HTTP │
└──────────────────────────┘                          └────────┬────────┘
                                                               │ WebSocket + статика
                                                      ┌────────▼────────┐
                                                      │ Браузер призрака│
                                                      │ (друг)          │
                                                      └─────────────────┘
```

Игра сама подключается к relay по исходящему соединению. Это значит, что **не нужно открывать порты на
компьютере игрока** и не нужен VPN: достаточно, чтобы relay был доступен из интернета.

## Быстрый старт

### 1. Установи BepInEx и interop (один раз)

Hard Bullet работает на Unity 6.5 с metadata v107, поэтому обычная авто-генерация BepInEx
не подходит. Подробности — в [`docs/SETUP.md`](docs/SETUP.md), автоматический путь:

```powershell
powershell -ExecutionPolicy Bypass -File tools/scripts/setup-interop.ps1 `
  -GameDir "D:\SteamLibrary\steamapps\common\Hard Bullet\bin"
```

### 2. Собери всё

```powershell
npm install
npm run build
dotnet build mod/HardMultiplayer.csproj -c Release
```

Мод скопируется в `BepInEx/plugins` автоматически, если в проекте указан правильный путь к игре.
Путь задаётся переменной окружения `HARDBULLET_DIR` или параметром `-p:GameDir=...`.
Вместо `dotnet build` можно использовать `tools/scripts/install-mod.ps1`.

### 3. Запусти relay

```powershell
npm start
```

По умолчанию relay слушает `http://0.0.0.0:8080`, WebSocket — `ws://127.0.0.1:8080/ws`, а браузерный
клиент доступен по `http://127.0.0.1:8080/`.

### 4. Запусти игру

В конфиге мода `BepInEx/config/hardmultiplayer.ghost.cfg` выставь:

```ini
[Relay]
Url = ws://127.0.0.1:8080/ws
Room = TEST
```

Запусти Hard Bullet. В логе `BepInEx/LogOutput.log` появится код комнаты. В игре код на несколько секунд
покажется текстом на экране.

### 5. Позови друга

Друг открывает `http://<адрес-relay>:8080/`, вводит код комнаты и имя. Всё.

Для игры через интернет подними relay на VPS или используй Cloudflare Tunnel — см.
[`docs/SETUP.md`](docs/SETUP.md).

## Что уже работает

- [x] Протокол v1 и общие DTO на TypeScript и C#.
- [x] Relay: комнаты, handshake, rate limit, мягкая проверка энергии/кулдаунов/хаоса, кэш карты и
      последнего снапшота для опоздавших, раздача статики, `/health`, `/api/rooms/:code`.
- [x] Браузерный клиент: лобби, карта, стены, игрок/враги/призрак/бочки, прицел, способности,
      горячие клавиши, энергия/хаос/кулдауны, журнал событий, звук, авто-реконнект.
- [x] Мок-игра (`tools/mock-game`) для разработки без VR.
- [x] Мод: WebSocket-клиент, мост к игровым API, спавн врагов, бочки, телекинез, полтергейст,
      манифестация, шёпот, карта из коллайдеров, снапшоты 10 Гц.
- [x] Скрипты сборки и установки.
- [ ] Полная проверка мода в игре — требует подключённого VR-шлема. В текущем окружении игра
      завершается на инициализации OpenXR с `XR_ERROR_FORM_FACTOR_UNAVAILABLE`.


## Требования

- Windows 10/11, Steam-версия Hard Bullet.
- VR-шлем (для реальной игры; для разработки клиента хватает мок-игры).
- .NET SDK 6+ (проверено на 10.0.400).
- Node.js 20+ (проверено на 24).
- BepInEx 6.0.0-be.791 Unity.IL2CPP x64 и сгенерированные interop-сборки.

## Важно

- Проект не распространяет файлы игры. Interop-сборки генерируются локально и не коммитятся.
- Мод авторитетен: клиент призрака не может напрямую двигать объекты, он только просит игру.
- Relay делает мягкие проверки, но окончательное решение — за модом.
- Не используй мод в соревновательных/античит-режимах, где он запрещён.
