# Hard Multiplayer

Асимметричный мультиплеер для **Hard Bullet**: игрок в VR проходит игру как обычно, а второй
человек без копии игры открывает браузер и играет за **призрака**. Призрак свободно летает
по карте в 3D от первого лица, спавнит врагов, бросает взрывные бочки, дёргает предметы,
устраивает полтергейст и на время манифестируется.

Перед применением способности VR-игрок видит голограмму намерения: где появится враг, куда
полетит бочка (со стрелкой), что дёрнет телекинез. Это даёт игроку шанс среагировать, а не
просто получить удар из ниоткуда.

Проект состоит из трёх частей:

| Часть | Где работает | Что делает |
| --- | --- | --- |
| **Мод** (`mod/`) | В игре, через BepInEx 6 IL2CPP | Читает состояние игры, исполняет команды призрака, рисует голограммы, отправляет снапшоты |
| **Relay** (`relay/`) | Node.js на любом хосте | Комнаты, WebSocket-мост, мягкая проверка команд, раздача браузерного клиента |
| **Клиент призрака** (`ghost-app/`) | Браузер друга | 3D-вид от первого лица, прицел, голограммы, способности, энергия, кулдауны, звук |

Другой человек **не должен владеть Hard Bullet и не должен устанавливать мод**. Ему нужен
только браузер и код комнаты.

```
┌──────────────────────────┐        WebSocket         ┌─────────────────┐
│ Hard Bullet + BepInEx мод│ ───────────────────────► │  Relay (Node)   │
│ (VR-игрок)               │ ◄─────────────────────── │  комнаты + HTTP │
└──────────────────────────┘                          └────────┬────────┘
                                                               │ WebSocket + статика
                                                      ┌────────▼────────┐
                                                      │ Браузер призрака│
                                                      │ (друг, 3D)      │
                                                      └─────────────────┘
```

Игра сама подключается к relay по исходящему соединению. Поэтому **не нужно открывать порты
на компьютере игрока** и не нужен VPN: достаточно, чтобы relay был доступен из интернета.

## Быстрый старт

### 1. Установи BepInEx и interop (один раз)

Hard Bullet работает на Unity 6.5 с metadata v107, поэтому обычная авто-генерация BepInEx
не подходит. Подробности — в [`docs/SETUP.md`](docs/SETUP.md), автоматический путь:

```powershell
powershell -ExecutionPolicy Bypass -File tools/scripts/setup-interop.ps1 `
  -GameDir "D:\SteamLibrary\steamapps\common\Hard Bullet\bin"
```

После первого запуска BepInEx **обязательно** выставь в
`BepInEx\config\BepInEx.cfg`:

```ini
[Logging]
UnityLogListening = false
```

Без этого BepInEx 6.0.0-be.791 падает на Unity 6.5 ещё до загрузки плагинов. Скрипт
`tools/scripts/install-mod.ps1` делает это автоматически.

### 2. Собери всё

```powershell
npm install
npm run build
dotnet build mod/HardMultiplayer.csproj -c Release
```

Мод скопируется в `BepInEx/plugins` автоматически, если в проекте указан правильный путь к
игре. Путь задаётся переменной окружения `HARDBULLET_DIR` или параметром `-p:GameDir=...`.
Вместо `dotnet build` можно использовать `tools/scripts/install-mod.ps1`.

### 3. Запусти relay

```powershell
npm start
```

По умолчанию relay слушает `http://0.0.0.0:8080`, WebSocket — `ws://127.0.0.1:8080/ws`,
а браузерный клиент доступен по `http://127.0.0.1:8080/`.

### 4. Запусти игру

В конфиге мода `BepInEx/config/hardmultiplayer.ghost.cfg` выставь:

```ini
[Relay]
Url = ws://127.0.0.1:8080/ws
Room = TEST
```

Запусти Hard Bullet. В логе `BepInEx/LogOutput.log` появится код комнаты. В игре код на
несколько секунд покажется текстом на экране.

### 5. Позови друга

Друг открывает `http://<адрес-relay>:8080/`, вводит код комнаты и имя. Всё.

Для игры через интернет подними relay на VPS или используй Cloudflare Tunnel — см.
[`docs/SETUP.md`](docs/SETUP.md).

## Что уже работает

- [x] Протокол v2 и общие DTO на TypeScript и C#.
- [x] Relay: комнаты, handshake, rate limit, мягкая проверка энергии и кулдаунов, кэш карты
      и последнего снапшота для опоздавших, preview, раздача статики, `/health`,
      `/api/rooms/:code`.
- [x] Браузерный клиент: лобби, 3D-сцена на three.js, свободный полёт, мышиный обзор,
      прицел-рейкаст, голограммы намерений, пять способностей, энергия/кулдауны, журнал
      событий, звук, авто-реконнект.
- [x] Мок-игра (`tools/mock-game`) для разработки без VR: 3D-карта, физика бочки, preview.
- [x] Мод: WebSocket-клиент, мост к игровым API, спавн врагов, летящие бочки, телекинез,
      полтергейст, манифестация, карта из коллайдеров с высотой, снапшоты 10 Гц,
      голограммы в мире.
- [x] Обход краша BepInEx ClassInjector: мод не добавляет собственные MonoBehaviour, а
      тикает из Harmony-патча на `PlayerRoot.Update`.
- [x] Скрипты сборки и установки.
- [ ] Полная проверка мода в VR — требует подключённого шлема и загруженного уровня.

## Требования

- Windows 10/11, Steam-версия Hard Bullet.
- VR-шлем (для реальной игры; для разработки клиента хватает мок-игры).
- .NET SDK 10 для Cpp2IL master (проверено на 10.0.400); для сборки мода достаточно 6+.
- Node.js 20+ (проверено на 24).
- BepInEx 6.0.0-be.791 Unity.IL2CPP x64 и сгенерированные interop-сборки.
- `UnityLogListening = false` в `BepInEx.cfg` (обязательный обход краша на Unity 6.5).

## Важно

- Проект не распространяет файлы игры. Interop-сборки генерируются локально и не коммитятся.
- Мод авторитетен: клиент призрака не может напрямую двигать объекты, он только просит игру.
- Relay делает мягкие проверки, но окончательное решение — за модом.
- Голограммы preview не тратят энергию и не создают игровых объектов.
- Не используй мод в соревновательных/античит-режимах, где он запрещён.
