# План реализации

## Цель

Сделать асимметричный мультиплеер для Hard Bullet:

- VR-игрок играет в обычную игру.
- Второй игрок без игры подключается через браузер и управляет призраком.
- Призрак свободно летает по 3D-карте от первого лица, спавнит врагов, бросает бочки,
  дёргает предметы, шумит и на время манифестируется.
- VR-игрок заранее видит голограмму намерения: врага, бочку со стрелкой, точку телекинеза.
- Мод и клиент живут в одном git-репозитории, но в разных папках.
- Связь идёт через relay, чтобы не требовать проброса портов у игрока.
- Документация и общение — на русском.

## Архитектурные решения

| Решение | Причина |
| --- | --- |
| BepInEx 6 IL2CPP, не MelonLoader | MelonLoader 0.7.3 не поддерживает metadata v107 (Unity 6.5). |
| Harmony-тик вместо своего MonoBehaviour | BepInEx 6.0.0-be.791 падает в ClassInjector на Unity 6.5; Harmony не требует инъекции типов. |
| `UnityLogListening = false` | Иначе BepInEx падает ещё до загрузки плагинов. |
| Relay как центральный хаб | Игра подключается исходящим WebSocket; друг может быть где угодно. |
| Браузерный клиент, не отдельный exe | Другу не нужно ничего устанавливать. |
| three.js + WebGL, не Canvas 2D | Нужен полноценный 3D-вид от первого лица и объёмные голограммы. |
| Мод — источник истины | Энергия, кулдауны, спавн и урон считаются в игре. |
| Relay — мягкий валидатор | Отсекает явный спам и рассинхрон, но не заменяет мод. |
| JSON over WebSocket | Просто отлаживать, достаточно для 10 Гц и десятков объектов. |
| Снапшоты 10 Гц | Плавная карта без лишней нагрузки. |
| Карта из BoxCollider с Y | Не требует рендера текстур, работает на любой сцене и даёт 3D-геометрию. |
| Preview 10 Гц | VR-игрок видит намерение, но канал не забивается лишними сообщениями. |

## Фазы

### Фаза 0. Разведка (готово)

- Определена версия Unity: `6000.5.8f1`, IL2CPP, metadata v107.
- Проверены MelonLoader и BepInEx; выбран BepInEx 6.
- Собран Cpp2IL master, сгенерированы dummy DLL.
- Сгенерированы 168 interop-сборок через Il2CppInterop CLI 1.5.3.
- Найдены игровые API: `EnemyFactory`, `EnemyRoot`, `PlayerRoot`, `ExplodingBarrel`,
  `PlayerTextOverlay`, `HealthContainer`.
- Найден обход краша ClassInjector: `UnityLogListening = false` + Harmony-тик.

### Фаза 1. Протокол v2 (готово)

- `shared/ts/protocol.ts` — источник истины.
- `shared/csharp/Protocol.cs` — зеркало для мода.
- Версия протокола: `2`.
- Определены handshake, снапшоты, 3D-карта, preview, команды, ack, события, камера, ping.
- Удалены хаос, `whisper`, `behind`, `distance`; добавлены `pitch`, `floorY`, `dirX/dirZ`,
  `power`, `fuse`, `preview`.

### Фаза 2. Relay (готово)

- WebSocket-сервер на `ws`.
- Комнаты 4–8 символов, один game и до двух ghost.
- Проверка протокола, роли, токена, размера сообщений, rate limit.
- Мягкая проверка энергии и кулдаунов.
- Пересылка и санитайзинг `preview`, `camera` (включая `pitch`), `cmd`.
- Кэш последней карты и снапшота для опоздавших.
- Раздача `ghost-app/dist` с SPA-fallback.
- `/health` и `/api/rooms/:code`.
- TTL пустых комнат.

### Фаза 3. Клиент призрака (готово)

- Лобби с кодом комнаты и именем, сохранение в `localStorage`.
- three.js-сцена: пол, стены, игрок, враги, бочки.
- Свободный полёт WASD + Space/C, ускорение Shift, мышиный обзор с pointer lock.
- Прицел-рейкаст по стенам/полу, координаты и `groundY`.
- Голограммы намерений: капсула врага, бочка со стрелкой, ромб телекинеза/полтергейста.
- Способности 1–5, ЛКМ и кнопка «Применить».
- Энергия, кулдауны, журнал событий, тосты.
- WebAudio-синтез без внешних файлов.
- Авто-реконнект и обработка late join.

### Фаза 4. Мод (готов к сборке, нужна проверка в игре)

- `Plugin.cs` — BepInEx-плагин, конфиг, запуск, Harmony-патч.
- `Patches.cs` — postfix на `PlayerRoot.Update`, вызывает `GhostDirector.Tick()`.
- `RelayClient.cs` — исходящий WebSocket, очередь сообщений, реконнект, ping.
- `GameBridge.cs` — безопасные обёртки над игровыми API, голограммы, бочки, эффекты.
- `GhostDirector.cs` — главный цикл, энергия/кулдауны, команды, preview, снапшоты, карта.
- `NullableAttributes.cs` — обход коллизии nullable-атрибутов в interop-сборках.
- Сборка `dotnet build` проходит, DLL копируется в `BepInEx/plugins`.
- Мод загружается в реальной игре, подключается к relay, сканирует сцену и отправляет карту.

## Критерии готовности v2

1. Игрок запускает игру с модом, видит код комнаты.
2. Друг открывает браузер, вводит код, видит 3D-карту и игрока.
3. Призрак летает в 3D и целится по стенам/полу.
4. Preview показывает голограмму врага/бочки/точки до каста.
5. Спавн врага действительно создаёт врага в игре.
6. Бочка летит по направлению призрака, стрелка исчезает в момент броска.
7. Телекинез двигает объект/врага.
8. Полтергейст мигает светом и толкает предметы.
9. Манифестация показывает призрака и заканчивается по таймеру.
10. Энергия и кулдауны не дают спамить.
11. При перезапуске relay игра и клиент переподключаются.

## Риски

| Риск | Митигация |
| --- | --- |
| Unity 6.5 / metadata v107 ломает interop | Зафиксированы версии Cpp2IL/Il2CppInterop и порядок генерации. |
| BepInEx ClassInjector крашит игру | `UnityLogListening = false`; мод не добавляет свои MonoBehaviour; тик через Harmony. |
| Игра падает без VR | Для разработки есть mock-game; финальная проверка — со шлемом. |
| Изменение игровых API после обновления | Все вызовы в `GameBridge` изолированы и логируются; есть RE-документ. |
| Читы через клиент | Мод — источник истины; relay только soft-check. |
| Сетевые задержки | 10 Гц снапшоты, preview 10 Гц, оптимистичный UI, реконнект, кэш состояния. |
| Утечка токена relay | Токен только для game-роли, хранится в конфиге; не коммитится. |
